# Smart Indian Calendar

A mobile-friendly single-file Indian calendar UI/UX starter.

## Included
- Month/year navigation
- Festival, national day, jayanti and history categories
- 2026 seeded festival data including Vishwakarma-ready architecture, Diwali, Govardhan Puja, Chhath Puja, Janmashtami, Dussehra, Ganesh Chaturthi, etc.
- Location selector
- Panchang/Astrology panel
- Day details modal
- Search and category filtering
- Dark mode
- Responsive mobile/tablet design

## Important
The UI deliberately separates fixed dates from Panchang-derived dates. Exact lunar festival dates can vary by year, location and regional Panchang conventions. The included 2026 entries are a starter dataset, while the architecture is ready for a verified Panchang/astronomical calculation engine.

Do not treat the demo sunrise/sunset or placeholder Panchang values as authoritative for religious observances.

## Run
Open `index.html` in any modern browser. No build step is required.
